# Phase 1 — 밀도 격자와 6.25% 경계

> **검증 대상: F-001의 "경계에서 4배 점프"가 실제 테이블에서도 계단으로 보이는가?**

## 왜 이게 필요한가

[F-001](../docs/findings.md)의 결과 — array 컨테이너 16.0ns/행 vs bitmap 4.0ns/행 — 은 **단일 청크를 통제한 마이크로벤치 4개 점**에서 나왔습니다.

실제 테이블은 다릅니다:

- 파일 하나에 청크가 **30개**
- 랜덤 삭제면 청크마다 카디널리티가 흔들림
- 경계 부근 밀도에서는 **한 파일 안에 array와 bitmap이 섞임**

그러면 계단이 평균으로 뭉개져 **완만한 경사**가 될 수 있습니다. 그렇다면 "삭제율에 따라 비용이 불연속 점프한다"는 프로젝트의 중심 주장은 통제된 실험실에서만 참인 얘기가 됩니다.

**지금 이 프로젝트에서 가장 검증 안 된 가정이고, 서사 전체가 여기 얹혀 있습니다.**

## 반증 가능한 예측

청크당 카디널리티는 `Binomial(65536, d)` 를 따릅니다.

| d | 평균 카디널리티 | 표준편차 | 4096 대비 |
|---|---|---|---|
| 5.00% | 3,277 | 55.8 | −14.7σ |
| 5.90% | 3,867 | 60.3 | −3.8σ |
| **6.25%** | **4,096** | **61.9** | **0.0σ** |
| 6.60% | 4,325 | 63.5 | +3.6σ |
| 7.00% | 4,588 | 65.3 | +7.5σ |

따라서:

1. **d = 6.25%에서 array:bitmap ≈ 50:50** — 임계값이 정확히 평균에 걸림
2. **전이 구간은 d ∈ [5.9%, 6.6%], 폭 0.7%p로 매우 좁다** (±3.6σ)
3. 그 바깥은 거의 100% 단일 타입

이 예측이 맞으면 → **계단은 살아남습니다.** 전이 폭이 0.7%p밖에 안 되니 로그 스케일 밀도 축에서는 사실상 수직입니다.
틀리면 → 격자 설계와 F-001의 해석을 다시 봐야 합니다.

`tools/container_curve.py`가 정규근사로 예측값을 계산해 실측과 나란히 출력하고, 오차가 15%p를 넘으면 "모델 재검토 필요"로 표시합니다.

## 실험 설계

### 밀도 축 (`d`)

삭제 술어: `pmod(hash(id, SEED), 10000) < D`

경계(625bp) 주변을 촘촘히 잡았습니다:

```
5  50  300  500  550  590  610  [625]  640  660  700  800  1200  5000     (bp)
0.05% 0.5% 3%  5%  5.5% 5.9% 6.1% 6.25% 6.4% 6.6% 7%  8%   12%   50%
```

### 왜 hash 분산인가

`F-006`에서 실측 확인: 목표 0.5%일 때 청크별 실제 밀도가 0.456~0.581%로 모였습니다. murmur3가 id에 대해 균일하므로 청크 단위 밀도도 목표 근처에 수렴합니다. **격자의 전제 조건이 성립함을 이미 확인한 상태**입니다.

### 비용 측정의 설계 이점

**밀도가 달라도 `contains()` 호출 횟수는 완전히 동일합니다.** `buildRowIdMapping`은 배치마다 `batchSize`번 무조건 프로브하기 때문입니다.

따라서 총 스캔 행 수를 고정(800만)하면:

```
DV 샘플 수  ∝  호출당 비용
```

분모가 설계상 동일하므로, 밀도 간 DV 샘플 수를 **직접** 비교할 수 있습니다. 별도 정규화가 필요 없습니다.

## 읽는 법

```
       d   청크수   array  bitmap   run   array%   예측%    평균카디널리티   표준편차
   6.25%     122      61      61     0    50.0%   50.0%           4,096      62.1
```

- **`array%` vs `예측%`** — 이항분포 모델이 맞는지. 크게 벌어지면 밀도가 청크에 균일하지 않다는 뜻이고, 그러면 hash 분산 가정을 재검토해야 합니다.
- **`표준편차`** — 예측(≈62)과 맞아야 합니다. 훨씬 크면 청크 간 밀도 편차가 이항분포보다 크다는 뜻입니다.
- **전이 구간 폭** — 이게 좁을수록 "계단"이라는 표현이 정당해집니다.
